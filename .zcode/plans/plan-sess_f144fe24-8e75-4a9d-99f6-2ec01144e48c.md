# AI 恋爱大师 + YuManus 自主规划智能体 — 实施规划

## 技术选型（已确认）

| 项目 | 选型 | 说明 |
|---|---|---|
| 后端 | Spring Boot 3.5.x + Spring AI 1.1.8 | 当前最稳定组合（Spring AI 2.0 需 Spring Boot 4，不采用） |
| 模型 | 阿里云通义千问（DashScope） | 用 `spring-ai-alibaba-starter-dashscope`，Key 走环境变量 `DASHSCOPE_API_KEY` |
| 向量库 | PostgreSQL + pgvector | 本地用 Docker 起 `pgvector/pgvector` 镜像；线上用阿里云 RDS PostgreSQL |
| 前端 | Vue 3 + Vite + TypeScript 独立工程 | SSE 流式渲染聊天界面、文档上传页、YuManus 智能体页 |
| MCP | Spring AI MCP Server (SSE) + MCP Client | 独立的 MCP 服务模块 + 恋爱大师作为客户端调用 |
| 智能体 | YuManus（ReAct 模式：Plan → Act → Observe 循环） | Java 实现，参考 OpenManus 思路 |
| 部署 | 阿里云函数计算 FC 3.0 | 自定义容器部署 + RDS pgvector |

## 分阶段实施计划（每完成一个阶段 = 一次 commit + push）

**阶段 0 — 项目初始化**
git init（main 分支）、.gitignore、README（项目简介 + 架构图）、目录骨架，首次推送建立远程 main。

**阶段 1 — 后端骨架 + 最简 AI 对话**
创建 Spring Boot 3.5 + JDK21 工程，接入 DashScope starter，写 `/ai/chat` 同步对话接口，用 curl 验证通义千问连通。⚠️ 此步需要你把 `DASHSCOPE_API_KEY` 配置为系统环境变量。

**阶段 2 — SSE 流式对话 + 恋爱大师人设**
`/ai/love_chat/stream` 返回 `Flux<ServerSentEvent<String>>`；自定义 System Prompt（"AI 恋爱大师"人设）；多轮会话记忆（ChatMemory + 会话 ID）。

**阶段 3 — Tool Calling 工具调用**
自定义工具：查询城市天气预报（代接 HTTP 天气 API）、生成 PDF 恋爱报告（iText）等，模型按需调用并流式返回结果。

**阶段 4 — RAG 知识库（含用户上传）**
Docker Compose 起 pgvector；ETL 管道（TikaDocumentReader 解析 PDF/Markdown → TokenTextSplitter 切分 → 向量化入库）；`QuestionAnswerAdvisor` 检索增强问答；上传接口 `POST /knowledge/upload`（用户上传文档 → 自动向量化入库）。

**阶段 5 — MCP 服务开发**
`mcp-server` 模块：`spring-ai-starter-mcp-server-webmvc`（SSE 传输），暴露"恋爱图片搜索（Pexels API）"等工具；主应用作为 MCP Client 挂载这些工具供模型调用。

**阶段 6 — YuManus ReAct 自主规划智能体**
实现 Agent 循环：任务拆解（Plan）→ 工具执行（Act）→ 结果观察（Observe）→ 迭代直到完成；注册所有工具（含 MCP 工具、RAG 检索、文件操作）；SSE 流式输出每步思考与执行过程。

**阶段 7 — Vue3 前端**
Vite + Vue3 + TS 独立工程：聊天页（SSE 逐字渲染 + 会话记忆）、知识库管理页（上传/列表）、YuManus 执行过程页；Vite 代理解决跨域。

**阶段 8 — 本地 Docker 联调**
docker-compose 一键起 pgvector + 后端，前后端联调全流程走通，写接口文档到 docs/。

**阶段 9 — 部署上线（阿里云 FC）**
后端打 Docker 镜像，用 Serverless Devs（`s.yaml`）部署到 FC 3.0 自定义容器；开通阿里云 RDS PostgreSQL + pgvector 插件，迁移向量表；前端构建产物部署（OSS+CDN 或 FC 静态托管）；配置环境变量与跨域，输出部署手册。

## 需要你准备的（阶段 1 之前）
1. **阿里云 DashScope API Key**（https://bailian.console.aliyun.com 开通），配成环境变量 `DASHSCOPE_API_KEY`
2. 阿里云账号（阶段 9 部署 FC + RDS 用）
3. 可选：Pexels API Key（MCP 图片搜索工具用，免费申请）
