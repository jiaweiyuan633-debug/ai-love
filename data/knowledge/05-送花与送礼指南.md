# 送花指南：花语与送礼原则

> 送花和送礼的核心不是"贵"，而是"对了"——对的花、对的时机、对的心意表达。

## 一、常见花语速查

| 花名 | 花语与适用场景 |
|---|---|
| 玫瑰 | 热恋、真爱。红玫瑰=炽热爱恋（适合表白与纪念日）；粉玫瑰=初恋与心动（适合暧昧升温期）；白玫瑰=纯洁的爱 |
| 向日葵 | 沉默的爱、忠诚与阳光。适合表白或鼓励对方 |
| 郁金香 | 体贴、优雅的爱。粉色郁金香代表永远的幸福 |
| 百合 | 纯洁、百年好合。适合纪念日与正式场合 |
| 满天星 | 甘愿守护的陪伴，常与玫瑰搭配表示真心 |
| 薰衣草 | 等待爱情、心心相印 |
| 栀子花 | 永恒的爱与约定，坚强而持久 |
| 桔梗 | 真诚不变的爱，适合异地恋表达思念 |
| 绣球 | 希望、团圆，寓意感情圆满 |
| 康乃馨 | 温馨的关怀。注意：康乃馨更常用于送长辈，送恋人需搭配其他花材 |

**选花速记**：表白选红玫瑰或向日葵；暧昧期选粉玫瑰或郁金香；异地恋选桔梗；道歉选黄玫瑰需谨慎（黄玫瑰也有道歉与逝去的爱之意，建议搭配小卡片说清楚）。

## 二、送礼四原则

1. **投其所好，而非掏空钱包**：留意对方随口提过想要的东西，"你上次说想要的那本绝版书"比大牌口红更打动人。
2. **心意大于价格**：手写卡片、亲手做的东西，性价比最高的浪漫。礼物价格要与关系阶段匹配，过早送贵重礼物会给对方压力。
3. **仪式感拉满**：同样的礼物，认真包装、写一段话、选一个有意义的时机送出，效果翻倍。
4. **实用与浪漫平衡**：全实用的礼物像采购，全浪漫的礼物容易吃灰。最佳组合是"一件她想要的实用物 + 一点浪漫小心意（花/手写卡片）"。

## 三、送礼时机参考

- **生日 / 纪念日**：必须记住，礼物提前准备，当天零点或见面时送出
- **情人节 / 七夕**：花 + 礼物是标配，餐厅要提前订
- **对方生病 / 低落时**：不一定要礼物，一份热粥、一次陪伴比什么都强
- **普通日子的小惊喜**：不定期的小礼物比"到点交作业"更让人心动
- **道歉时**：先真诚沟通再送礼，礼物不能代替道歉，只能为道歉加分

## 四、避雷清单

- 送对方禁忌或忌讳的东西（先了解对方的喜好与过敏源）
- 在对方公司当众送贵重礼物（压力山大）
- 转手礼物或明显敷衍的凑数礼物
- 用礼物代替陪伴和沟通

> 一句话总结：最好的礼物是"我记得你说过"。
